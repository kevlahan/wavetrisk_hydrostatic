## Corrections during qualification

The full runtime oracle exposed untouched mass RK scaffold slots that were NaN
instead of the original +0 initialization. The return now preserves +0 for those
unused output slots; absent live graph producers remain errors.

An initial four-rank trajectory timed out after 2400 seconds during the last
step. A bounded CPU stack sample identified producer lookup as the main sampled
computation. The old hash maps contiguous rank-local IDs into overlapping ranges;
linear probing made repeated producer reads expensive. The corrected integer
mixer removes that clustering without changing numerical evaluation order. Raw
CPU samples and the timed-out run are preserved under `.stage235-validation`.
