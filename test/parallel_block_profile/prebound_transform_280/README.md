# Stage280 exchange qualification

The optional prebound-provider compiler path uses a current, unique ownership
directory for phases without competing writes. All outer writer-order proofs
and epoch/state guards remain. The48-case optimized/checked harness exercises
new/default/shared paths at1/4 ranks, including invalid providers, competing
writers, alias cycles, signs, empty ranks and large payloads. Builds/runs are serial.

Use exchange_units.py with --source pointing at the solver checkout and --output
a fresh nonexisting output directory. This helper directory is not a sealed
cluster kit. Full source-bound solver replays, manifests and GCC13 logs are in
.stage280-validation. See docs/parallel-blocks-stage280-prebound-repair.md.
